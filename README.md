# منصة الامتحان المشترك – قسم هندسة وتكنولوجيا البصريات
### Optics Common Exam Platform · الثيم البنفسجي الملكي والتحكم الإداري الكامل

منصة ويب متكاملة، ثابتة (Static Web Application)، مصممة لطلبة قسم **هندسة وتكنولوجيا البصريات** للوصول إلى مقررات ومحاضرات الامتحان التقويمي الوزاري المشترك لجميع المراحل الدراسية، مع قارئ PDF مدمج، محرك بحث سريع، وتأثير التمرير السلس (Smooth Scrolling)، ولوحة تحكم متكاملة للمشرف (Admin Panel) لإدارة كافة نصوص الموقع وبطاقات الهيرو وصفحة حول المنصة، ورفع الملفات من الجهاز، وإدارة حسابات الطلاب مع تغيير الرموز واليوزرات.

جاهزة للنشر المباشر والمجاني على **GitHub Pages**.

---

## 🌟 مميزات المنصة والتحديثات الجديدة

1. **التحكم الشامل في جميع عناصر الموقع للمشرف**:
   - إمكانية تعديل اسم المنصة، اسم القسم، الكلية، والسنة الدراسية.
   - إمكانية تعديل نصوص وشارات الشاشة الرئيسية وقسم الهيرو (Hero Section).
   - **تعديل بطاقة قسم هندسة وتكنولوجيا البصريات التوضيحية**:
     - تعديل العنوان الأساسي للبطاقة.
     - تعديل النص الوصفي تحت العنوان.
     - تعديل وسوم التخصصات الأربعة («البصريات الهندسية»، «فحص الانكسار»، «العدسات اللاصقة»، «أمراض العين»).
   - **تعديل محتوى صفحة «حول المنصة»**: تعديل العنوان الرئيسي، العنوان الفرعي، والنبذة التعريفية الأكاديمية كاملة.

2. **رفع ملفات PDF من ملفات الجهاز مباشرة**:
   - تخصيص حقل لرفع الملف من جهاز الكمبيوتر أو الهاتف عند إضافة أو تعديل محاضرة.
   - قراءة الملف وحفظه محلياً في المتصفح مع استخراج الاسم والحجم وعدد الصفحات تلقائياً.
   - فتح الملف وتصفحه فوراً داخل **قارئ PDF الداخلي** دون الحاجة لرفعه إلى سيرفر خارجي!

3. **نظام حسابات المستخدمين والطلاب المسجلين**:
   - إمكانية إنشاء حساب جديد لأي طالب عبر إدخال (الاسم الكامل، اسم المستخدم/يوزر نيم، رمز المرور، والمرحلة الدراسية).
   - إخفاء بيانات المشرف من واجهة تسجيل الدخول لحماية الخصوصية.
   - **قسم إدارة المستخدمين في لوحة المشرف**:
     - عرض جدول بجميع حسابات الطلاب المسجلين مع تاريخ التسجيل والمرحلة.
     - إمكانية تغيير رمز المرور واسم المستخدم لأي طالب مباشرة من لوحة المشرف.
     - إمكانية إضافة حسابات جديدة أو حذف أي حساب طالب.

4. **الثيم البنفسجي الملكي والتمرير السلس**:
   - تصميم Apple بنفسجي راقٍ يدعم الوضعين الداكن والفاتح.
   - تمرير سلس (Smooth Scrolling) انسيابي بين أقسام الصفحة الرئيسية.

## 🚀 كيفية استخدام الطريقة الأولى والثانية في رفع التحديثات

### الطريقة الأولى: النشر التلقائي بنقرة زر واحدة عبر GitHub API (موصى بها)
1. ادخل إلى لوحة تحكم المشرف (اسم المستخدم: `it7asan`، الرمز: `20032003`).
2. اذهب للتبويب رقم **5: نشر ومزامنة البيانات للجميع**.
3. أدخل اسم مستودعك (مثال: `yourname/optics-exam-platform`).
4. أدخل رمز وصول GitHub (Personal Access Token) مع صلاحية `repo`.
5. اضغط زر **«🔍 فحص واختبار الاتصال والتوكن»** للتأكد من صحة الإعدادات.
6. اضغط زر **«🚀 نشر التعديلات فوراً لجميع الطلاب على GitHub»** (أو الزر السريع الأخضر بأعلى لوحة الإدارة).
7. سيتصل الموقع بـ GitHub مباشرة ويقوم بعمل Commit وتحديث لملف `data/exams.json`. خلال 30 إلى 60 ثانية، يعيد GitHub Pages النشر وتظهر التعديلات لجميع الطلاب حول العالم!

### الطريقة الثانية: النشر اليدوي باستبدال ملف exams.json (بدون الحاجة لأي Token)
1. بعد تعديل المواد أو المحاضرات أو الإعدادات في لوحة المشرف، اضغط زر **«📥 1. تحميل ملف exams.json المحدّث»**.
2. اضغط زر **«📂 2. فتح مجلد data في مستودعك على GitHub»** (أو افتح مستودعك على GitHub وادخل لمجلد `data`).
3. اضغط `Add file` > `Upload files` واسحب ملف `exams.json` الذي قمت بتنزيله، ثم اضغط الزر الأخضر **Commit changes**.
4. فوراً سيعيد GitHub Pages البناء ويظهر التحديث لجميع الطلبة.

## 🚀 النشر على GitHub Pages

1. ارفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git init
   git add .
   git commit -m "Optics Platform Full Admin Customization & User Management"
   git branch -M main
   git remote add origin https://github.com/USERNAME/optics-exam-platform.git
   git push -u origin main
   ```
2. في GitHub، ادخل إلى **Settings** > **Pages**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. سيعمل الموقع مباشرة على: `https://USERNAME.github.io/optics-exam-platform/`.

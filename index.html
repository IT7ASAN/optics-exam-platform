منصة الامتحان المشترك – قسم تقنيات البصريات

Optics Common Exam Platform · للعام الدراسي 2026 - 2027

تم تطوير هذه المنصة لتكون المرجع الرسمي والأول لطلبة قسم تقنيات البصريات للوصول الفوري والمنظم إلى جميع ملفات الامتحان التقويمي الوزاري المشترك. تم تصميم الواجهة بمعايير تطبيقات Apple الراقية بالثيم البنفسجي، لتعمل بكفاءة مطلقة على أجهزة iPhone، iPad، Mac، وشاشات الكمبيوتر.

تثبيت المنصة كتطبيق على هاتفك وحاسوبك يمكنك إضافة المنصة إلى الشاشة الرئيسية لفتحها وتصفحها بسرعة وسهولة مثل أي تطبيق.

أجهزة iPhone و iPad

متصفح Safari
  1. افتح المنصة عبر متصفح Safari الرسمي.
  2. اضغط على زر المشاركة (Share ) أسفل الشاشة.
  3. مرر للأسفل واختر «إضافة إلى الشاشة الرئيسية» (Add to Home Screen).
  4. اضغط على «إضافة» (Add) بالأعلى لتظهر المنصة كتطبيق مستقل بشعارها!

أجهزة Android و Galaxy

متصفح Chrome
  1. افتح المنصة عبر متصفح Google Chrome.
  2. اضغط على قائمة الخيارات (⋮) في الزاوية العلوية أو السفلية.
  3. اختر «تثبيت التطبيق» (Install app) أو «إضافة إلى الشاشة الرئيسية».
  4. أكّد التثبيت لتظهر أيقونة المنصة فوراً في شاشة التطبيقات.

أجهزة الكمبيوتر واللابتوب

Windows / Mac
  1. افتح الموقع عبر متصفح Chrome أو Edge.
  2. ستلاحظ ظهور أيقونة تثبيت صغيرة في أقصى شريط الرابط بالأعلى.
  3. اضغط على الأيقونة ثم اختر «تثبيت» (Install) لتفتح المنصة كنافذة مستقلة فائقة السرعة.

اسم المستخدم (يوزر نيم) الاسم الكامل المرحلة الدراسية تاريخ التسجيل الإجراءات

هل يجب رفع ملفات المشروع على المستودع أولاً، أم فقط إدخال بيانات المستودع؟

نعم، يجب رفع ملفات المشروع كاملة إلى مستودع GitHub لأول مرة فقط!
لكي يعمل موقعك على رابط GitHub Pages (مثل https://username.github.io/optics-platform/)، يحتاج GitHub إلى ملفات الموقع الأساسية (index.html، والتنسيقات، والشعار، وقارئ الـ PDF).

المرحلة 1 تأسيس الموقع (تُعمل مرة واحدة فقط):

ترفع ملفات المشروع كاملة إلى مستودع GitHub وتفعّل خيار Settings → Pages. سيعمل رابط الموقع مباشرة.

المرحلة 2 التحديثات اليومية والمستمرة:

بعد أن يعمل الموقع، لا تحتاج لإعادة رفع المشروع كاملاً أبداً! فقط استخدم الطريقة الأولى (بنقرة زر عبر التوكن) أو الطريقة الثانية (استبدال ملف exams.json فقط).

✨ ملفات الموقع تظل ثابتة، بينما تتغير بيانات المواد والمحاضرات تلقائياً للجميع.

الطريقة 1: النشر المباشر إلى مستودع GitHub بنقرة زر واحدة (عبر Token)

موصى به لتحديثات سريعة

أدخل بيانات مستودعك مرة واحدة فقط (يتم حفظها بأمان في جهازك). يمكنك فحص الاتصال للتأكد من صحة التوكن، ثم الضغط على زر النشر ليقوم الموقع بتحديث ملف data/exams.json في المستودع فوراً!

اسم حسابك على GitHub يليه اسم المستودع (أو الصق رابط المستودع كاملاً)
الفرع الذي يُنشر منه موقع GitHub Pages (غالباً main)
🔗 إنشاء Token جديد مجاناً في ثوانٍ
رمز مجاني من GitHub بصلاحية repo أو public_repo ليتمكن المتصفح من إرسال التحديث لمستودعك.

الطريقة 2: استبدال ملف exams.json يدوياً (بدون الحاجة لـ Token نهائياً)

سهل ومضمون 100%

إذا كنت لا ترغب في إدخال GitHub Token، هذه الطريقة سهلة جداً ولا تستغرق سوى دقيقة واحدة لتحديث المنصة لجميع الطلاب:

1

حمّل الملف المحدث

اضغط زر التحميل أدناه لتنزيل أحدث نسخة من ملف exams.json لجهازك.

2

افتح مجلد data

اضغط زر «فتح مجلد data في مستودعك» لفتح الصفحة في GitHub مباشرة.

3

اسحب الملف واضغط Commit

اسحب الملف المحدث واضغط Commit Changes. وخلال 30 ثانية تظهر التعديلات للجميع!

عذراً، الصفحة غير متوفرة

الصفحة أو الملف الذي تحاول الوصول إليه غير موجود أو تم نقله.
